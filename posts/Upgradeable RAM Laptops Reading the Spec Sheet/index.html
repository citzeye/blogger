Two laptops, same 16 GB of memory, same processor generation, same price bracket. One of them you can double the memory on in four minutes with a screwdriver. The other cannot be upgraded at all, ever, and no amount of money changes that after you buy it.

The difference is not advertised, because it is not a specification anybody markets. It is a physical arrangement, and the only place it is written down is in the manufacturer's own documents — where each brand uses different words for the same hardware.

That is the whole problem, and it is why so many people get this wrong twice: once when buying, and once again when a retailer tells them it is fine.

Two words that mean opposite things

Laptop memory comes in two arrangements, and only one of them is upgradeable.

Socketed means the memory sits in a slot on the motherboard as a separate removable module — technically a SODIMM, the short notched stick you clip in and out. You can pull one out and put a bigger one in. On most laptops with this arrangement there are two slots.

Soldered means the memory chips are bonded directly to the board. There is no slot, no clip, and no way in without replacing the entire motherboard. The capacity you buy is the capacity you keep, forever.

Thin laptops are almost always soldered, purely for physical reasons: leaving slots in would make the machine thicker. That is why upgradeability and thinness trade against each other, and why nearly every sub-14-inch notebook today is sealed.

Why the spec sheets lie to you

Here is HP's own Maintenance and Service Guide, describing four different laptops:

HP modelHP's wording, verbatimReality
Pavilion 15 Laptop PC "Two SODIMM memory module slots, non-customer-accessible/non-upgradable" Soldered
HP 15 Laptop PC "Two SODIMM slots, not customer accessible or upgradeable" Soldered
HP 15 Notebook PC "Two SODIMM customer-accessible/upgradable memory module slots" Upgradeable
OMEN by HP 15 "Two SODIMM slots, customer accessible/upgradeable" Upgradeable

Every row says "two SODIMM slots". Two of the four are sealed and two are open, and the slot count alone tells you nothing. The only word that separates them is customer-accessible — which is why the useful shorthand that circulates on HP's own support forum is this:

"Soldered memory is referred to as ONBOARD on HP documentation, so RAM is not soldered."

HP is at least consistent in one respect: if a manual never uses the word "onboard" for the memory, the memory is in sockets. But you have to know that convention before you can use it, and nobody tells you that up front.

Lenovo is much clearer, because its public spec reference — PSREF, the same document Lenovo's own sales and support teams work from — has a dedicated field. It reads exactly as written, with no interpretation needed:

Lenovo model"Memory Slots", verbatimMax
ThinkPad E14 Gen 6 (Intel) "Two DDR5 SODIMM slots, dual-channel capable" 64GB DDR5-5600
ThinkPad L14 Gen 6 (Intel) "Two DDR5 SODIMM slots, dual-channel capable" 64GB DDR5-5600
ThinkPad E14 Gen 6 (AMD) "Two DDR5 SODIMM slots, dual-channel capable" 64GB, but "for special bid only"
IdeaPad Slim 3 15IRH10 "One memory soldered to systemboard, one DDR5 SODIMM slot" 24GB (8GB fixed + 16GB)
ThinkPad 11e 5th Gen "4GB soldered memory, not upgradable" 4GB

ASUS publishes the same information in the spec table on the product page, using the phrase "on board" for soldered memory — the same trick as HP, in a different font.

  • Vivobook 15 (F1502) — "8GB DDR4 on board 8GB DDR4 SO-DIMM Max Total system memory up to:16GB". One slot, 8GB permanently attached.
  • Vivobook 16 (M1607) — "Max Total system memory up to:32GB", one DDR5 SO-DIMM slot.
  • TUF Gaming A15 — "16GB DDR5-4800 SO-DIMM, Max Capacity:64GB", two DDR5 SO-DIMM slots. Nothing soldered.
  • TUF Gaming F16 (2025) — "16GB DDR5 on board, 16GB DDR5-5600 SO-DIMM, Max Capacity:64GB", two slots.

Note that last pair. Two laptops from the same product family, one with all its memory removable and one with half of it soldered on. "TUF Gaming" is not a specification.

The one number that is comparable across brands

Vendor prose is incomparable, but one third-party field is not. Kingston publishes a compatibility database for every laptop it sells memory for, and for each model it gives a plain socket count:

ModelKingston says
Lenovo ThinkBook 14 G6 IRL"2 Socket(s)", 64GB max
ASUS TUF Gaming F16 (2024)"2 Socket(s)", 32GB max
ASUS Vivobook 15 (X1504)"1 Socket(s)", "4 GB (Non-removable)", 12GB with 4GB soldered
Lenovo ThinkPad Twist S230u"0 Slot(s) (Memory soldered to systemboard)"

"N Socket(s)" means the same thing on every row. That makes it the fastest way to check a specific machine: search the model on Kingston's memory finder and read one number. It is also the only source in this list that is written down consistently enough to compare across brands.

The 30-second check, before you buy anything

You can settle this on any laptop in about half a minute, without opening it and without buying it first.

Press Ctrl+Shift+Esc to open Task Manager, go to the Performance tab, and click Memory in the left column. Read the Slots used field.

  • "2 of 2" — both slots filled, both removable. Fully upgradeable.
  • "1 of 2" — one slot free. The best case: you can add a module without removing anything.
  • "0 of 0", or no Slots used field at all — soldered. This is the rule ASUS states explicitly: "If Task Manager does not show a 'Slots used' field, or if it shows '0 of 0 slots,' the RAM is soldered."

If you want the ceiling the board itself accepts rather than what is fitted today, HP documents a second command:

wmic memphysical get maxcapacity

"The capacity is shown in Kilobytes, so you have to convert to Gigabytes by dividing the number provided in the report by 1,048,576."

Be honest about the limits of this. It is a strong signal, not proof. There are documented cases of Task Manager reporting 32GB of headroom on machines that are physically sealed, because the firmware reports what the memory controller supports rather than what you can physically reach. Where the two disagree, the service manual wins.

Two traps that cost people their money

The "max memory" number is a ceiling, not an invitation

PSREF lists the ThinkPad E14 Gen 6 (AMD) at "Up to 64GB DDR5-4800" — and then adds, in the notes, "The 64GB memory is for special bid only." A spec sheet read carelessly tells you 64GB is a supported configuration. It is not something you can order, and not something you are expected to fit.

The IdeaPad Slim 3 15IRH10 has the same shape of problem without the footnote. It has one soldered 8GB chip and one slot, so its real ceiling is "Up to 24GB (8GB soldered + 16GB SODIMM)". You cannot reach 32GB no matter how many 16GB modules you buy, because the 8GB is permanent and the arithmetic does not work. Every laptop with soldered memory has a ceiling like this, and it is always lower than the retailer's "up to" suggests.

The RAM speed you get is not the speed you paid for

Both Lenovo and ASUS footnoted this independently, in almost identical words:

  • Lenovo, IdeaPad Slim 3 15IRH10: "Installed memory is actually DDR5-5600 but runs as DDR5-4800 due to platform limitation."
  • ASUS, TUF Gaming A15: "Memory specification is rated for 5600MHz, but due to a CPU limitation is limited to 4800MHz."

This is not a defect and it barely affects anything you will notice. It does mean that buying faster memory than the spec sheet quotes is buying money you cannot spend — the processor will run it slower either way.

What to actually look for

Three questions, in this order, and they settle the decision:

  1. Does Task Manager show "1 of 2" or "2 of 2"? If it shows slots, you can upgrade. If it shows none, you cannot, and nothing else on the page will change that.
  2. Does the vendor document say "on board" or "onboard" anywhere in the memory section? If yes, part of your memory is fixed for the life of the machine.
  3. Is the stated maximum compatible with the soldered amount? The ceiling is soldered memory plus whatever fits in the slots, not a headline number.

If a retailer tells you a laptop's memory can be upgraded, ask them which slot. If the answer names a document — PSREF, a service manual, a Kingston socket count — you have your answer. If it does not, you are being told what you want to hear.

This matters more when the laptop is meant to last. A school machine bought cheap and soldered is a machine you replace in four years; the same machine with one free slot can be carried through a whole course of study. It is worth spending two minutes on before you spend any money at all — the reasoning behind our cheap laptops for school that hold up picks assumes you have checked this first.

It also cuts against the "AI laptop" pitch. Much of what those machines advertise is a neural processor that the machine's own memory cannot usefully feed, and several of the models in this article ship with half their memory soldered. We looked at that gap separately in budget laptops advertised as AI with no AI chip.

One more thing worth knowing

Even on a fully socketed laptop, memory is not the only upgrade worth having. Several models in these tables ship with short M.2 2242 SSDs, a smaller-than-standard form factor: the IdeaPad Slim 3 15IRH10 takes "Two M.2 2242 PCIe 4.0 x4 slots" and nothing else. A common 2280 drive will not physically fit, and that mistake is easier to make than the RAM one because nobody warns you about it.

Both upgrades are worth doing on the right machine. On the wrong machine, neither is possible, and the only fix is to buy a different computer — which is the expensive lesson this article exists to prevent.
